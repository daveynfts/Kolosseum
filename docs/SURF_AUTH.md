# Surf API authentication and usage metadata

On 25 September 2026, the first saved API key produced HTTP 401 on authenticated Data and Chat requests. An anonymous Data API call returned HTTP 200, so that anonymous result was never proof that the key worked. The user replaced the key in the Git-ignored .env.local. With the replacement key, an authenticated GET https://api.asksurf.ai/gateway/v1/market/price?symbol=SOL returned HTTP 200, and a real POST /v1/responses using surf-2.0 completed for a SCEX KOL. No API key is printed in the diagnostic output or committed to Git.

The documented GET /v1/me/credit-balance returned HTTP 401 even with this working replacement key. This is a route-specific discrepancy between Surf's documentation and observed gateway behavior; its cause is unknown. Kolosseum therefore checks the authenticated SOL price route before opening paid routes, and the real Chat call confirms Chat access. A successful Data preflight alone cannot guarantee the subsequent Chat call will succeed. The first Data call can consume standard market-data credits; Surf documents a three-minute zero-credit repeat window.

Run npm run research:check-surf-auth after changing SURF_API_KEY, then restart the research sidecar. HTTP 401 means the authenticated Data request was rejected, HTTP 402 indicates no available credits, and other failures are reported as unavailable. The check never logs the key or calls Chat. Keep the key only in server-side .env.local.

Surf's pricing page says each response carries meta.credits_used, but the successful non-streaming Chat response in this run contained token usage and no meta.credits_used. For a new report in that case, Kolosseum labels creditsSource as published-rate and uses Surf's fixed surf-2.0 tariff for the requested reasoning effort: none 20, minimal 30, low 50, medium 120, high 150, xhigh 200 credits. A report generated from the encrypted local cache records zero new Surf credits and creditsSource cache. Deep x402 metering uses the provider amount when supplied or the published tariff when omitted, at the configured $0.006 per credit and $1.00 cap. The verified none-effort deep purchase charged $0.12 sandbox USDC.

Official references: [Surf Responses API](https://platform.asksurf.ai/docs/chat/responses), [Surf credits and pricing](https://platform.asksurf.ai/docs/pricing), [Surf Data API overview](https://platform.asksurf.ai/docs/data-api/overview).
